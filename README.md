# E-Commerce QA Automation

This is a QA automation project that I am building to learn and practice web application testing.

The main idea is to test an e-commerce website and automate common user actions such as login  searching for products  adding products to the cart and going through the checkout process.

Along with automation I will also create test cases and document bugs that I find while testing the application.

## Workflows

### 1. Login Workflow

```text
Open Website
    ↓
Go to Login Page
    ↓
Enter Username
    ↓
Enter Password
    ↓
Click Login
    ↓
Verify Login
```

### 2. Product Search Workflow

```text
Login
    ↓
Open Home Page
    ↓
Search for Product
    ↓
View Search Results
    ↓
Open Product
    ↓
Verify Product Details
```

### 3. Shopping Cart Workflow

```text
Login
    ↓
Search Product
    ↓
Open Product
    ↓
Add Product to Cart
    ↓
Open Cart
    ↓
Verify Product
    ↓
Update or Remove Product
```

### 4. Checkout Workflow

```text
Login
    ↓
Add Product to Cart
    ↓
Open Cart
    ↓
Proceed to Checkout
    ↓
Enter Required Details
    ↓
Review Order
    ↓
Place Order
    ↓
Verify Order
```

### 5. Logout Workflow

```text
Login
    ↓
Perform User Actions
    ↓
Click Logout
    ↓
Verify User is Logged Out
```
